# RouteComment

GPSログ、地図画像、コメントを重ねて表示できる、オリエンテーリングの振り返り用Webアプリケーションです。

- **デモ:** [routecomment.pages.dev](https://routecomment.pages.dev/)
- **マニュアル:** [manual/00-index.md](manual/00-index.md)

## 主な機能

- GPSログの読み込みと、速度に応じた色分け表示
- 背景地図との2点指定による、地図画像の簡易的な位置合わせ
- GPSログのアニメーション再生
- 標高・心拍数・ペースのグラフ表示と再生位置の同期
- 実走ルートとは別の、プランしたルートの手動描画
- 地図上の任意の場所へのコメント配置
- タイムライン上の時刻や区間に紐づけたコメントの登録と、アニメーション再生中の自動表示

## 技術スタック / セットアップ

クライアント（ブラウザ）完結型の構成です。

### 使用している技術・ライブラリ

- **コア:** Vite, React, TypeScript
- **状態管理:** Zustand
- **地図・地理空間:** MapLibre GL JS
- **データ処理・ファイル:** @tmcw/togeojson, JSZip
- **グラフ描画:** uPlot
- **地図タイル・標高:**
  - 地図表示: OpenFreeMap
  - 地形・標高タイル: Mapterhorn

### 開発の始め方

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev      # http://localhost:5173
```
