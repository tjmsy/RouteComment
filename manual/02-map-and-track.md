# 地図とGPSログ

## GPXを追加・差し替える

作成時に読み込まなかった場合や別のログを使う場合は、画面上部の **プロジェクト** を開き、**GPX** を選びます。読み込むと、距離・時間・累積標高・平均心拍数が利用可能なデータに応じて表示されます。

GPXにトラックポイントがない場合は読み込めません。トラックの時刻情報がない場合、時間に連動する表示は意図どおりに使えないことがあります。

## 地図画像を追加する

**プロジェクト** の **地図画像** からPNG、JPEG、またはWebPを追加できます。追加後は **位置合わせ** を選び、2組の対応点で地図画像を背景地図に重ねます。

位置合わせをやり直すときも、同じ **位置合わせ** を選びます。実走トラックと地図上の特徴が大きくずれる場合は、離れた2点を選び直してください。

## GPSトラックの見方

**レイヤー** では、GPSトラックの表示／非表示、速度による色分け、線の太さを変更できます。速度の変化は、減速した箇所を見つける手がかりになりますが、GPSの誤差や受信状態の影響も考慮してください。

## 背景地図

**レイヤー** の **背景地図** で背景地図を表示／非表示にできます。トラック再生中は切り替えできないため、いったん再生を停止してください。

背景地図は地図画像の位置合わせや周辺状況の確認に便利です。一方で、競技地図上の細部を分析する際は、地図画像との重なりを優先して確認してください。
