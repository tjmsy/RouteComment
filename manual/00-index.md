# RouteComment マニュアル

RouteCommentは、オリエンテーリングのGPSログ、地図画像、走行中の判断を一つのプロジェクトにまとめ、振り返りや共有に使うためのアプリケーションです。

実走トラックと自分の計画ルートを地図上で見比べながら、迷い始めた地点、確認した情報、選んだルート、次回に生かす判断を記録できます。

## できること

- GPX形式のGPSログを読み込む
- 地図画像を背景地図に位置合わせして重ねる
- 計画したルートを複数描く
- 地図上または走行時間にひも付けてコメントを残す
- トラックを再生し、コメントをタイミングに合わせて表示する
- プロジェクトをZIPファイルとして保存・読み込みする

## 使い始める前に

JavaScriptとWebGLを利用できる最新のブラウザをおすすめします。地図画像はPNG、JPEG、WebP、GPSログはGPX形式を用意します。GPXに時刻が含まれていると、トラック再生と時間に連動するコメントを使えます。

背景地図や標高の補完にはインターネット接続が必要です。地図画像、GPX、ルート、コメントの編集とZIPの保存・読み込みは、背景地図が利用できない場合でも行えます。

## 基本の流れ

1. プロジェクトを作成し、GPXと地図画像を読み込む
2. 地図画像を位置合わせする
3. 実走トラックを見ながら、計画ルートとコメントを追加する
4. 必要に応じて再生・グラフ・表示レイヤーで振り返る
5. ZIPとして保存し、次回または他者との共有に使う

[最短で使う](./01-getting-started.md) から、最初のプロジェクトを作成できます。
