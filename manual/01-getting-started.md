# 最短で使う

ここでは、GPSログと地図画像を使って、最初の振り返りを保存するまでを説明します。

## 1. プロジェクトを作成する

最初の画面で **プロジェクトを作成** を選びます。まず **GPX** を選択してGPSログを読み込みます。ログがない場合は **GPXをスキップ** を選んで後から追加できます。

続けて **地図画像** を選び、使用する地図のPNG、JPEG、またはWebP画像を読み込みます。こちらもスキップ可能です。

## 2. 地図画像を位置合わせする

地図画像を読み込むと、位置合わせの画面になります。地図画像と背景地図で同じ場所を2組選ぶことで、位置・回転・縮尺を合わせます。

1. 地図画像上の分かりやすい特徴点を選ぶ
2. 背景地図上の同じ場所を選ぶ
3. 地図画像上で、1点目から十分に離れた2点目を選ぶ
4. 背景地図上の対応する2点目を選ぶ
5. 重なりを確認し、**完了** を選ぶ

道路の交差点、橋、建物の角など、両方で特定しやすく、互いに離れた点を選ぶと精度が上がります。必要なら地図画像の不透明度を下げて確認してください。

## 3. プロジェクト名を付ける

画面上部の **プロジェクト** を開き、プロジェクト名を入力します。大会名、日付、練習名など、後から判別しやすい名前をおすすめします。

## 4. 最初のルートとメモを作る

**編集** を選び、**プラン** から **プランを追加** を選択します。地図をクリックまたはタップして、計画ルートの点を順に置きます。終わったら **完了** を選びます。

続けて **編集** から **ノート** を選び、振り返りたい場所を地図上で選んで文章を入力します。

## 5. 保存する

**プロジェクト** を開いて **ZIPを保存** を選びます。作成されるZIPがプロジェクト全体の保存ファイルです。編集後は、共有やブラウザの変更に備えて新しいZIPを保存してください。

次は、[地図とGPSログ](./02-map-and-track.md) で各データの扱いを詳しく説明します。
