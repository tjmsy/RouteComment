# ルートとコメント

## 計画ルートを描く

画面上部の **編集** から **プラン** を選びます。

1. **プランを追加** を選ぶ
2. 地図上を順にクリックまたはタップして点を追加する
3. 頂点をドラッグして位置を調整する
4. 頂点をダブルクリック、または長押しして不要な点を削除する
5. **完了** を選ぶ

複数のルートチョイスを残す場合は、プランを追加して色を変えます。表示のオン／オフと線の太さは **レイヤー** から調整できます。

## コメントの種類

**編集** から、目的に応じて3種類のコメントを追加できます。

| 種類     | 使いどころ                     | 操作                                             |
| -------- | ------------------------------ | ------------------------------------------------ |
| ノート   | 特定の場所に残す考察           | 地図上の位置を選び、文章を入力する               |
| つぶやき | ある区間の判断や迷いを残す     | トラック上で始点・終点を順に選び、文章を入力する |
| テロップ | 再生中の特定時刻に短く表示する | トラック上の位置を選び、1行の文章を入力する      |

## 分析に残す内容

コメントには、結果だけでなく判断の根拠を残すと次の振り返りにつながります。たとえば「遅れた」だけでなく、見ていた地形、確信した地点、迷いに気付いたきっかけ、立て直し方を記録します。

ノートはドラッグで移動でき、必要に応じてサイズも調整できます。つぶやきの始点・終点やテロップの表示位置は、トラック上のマーカーをドラッグして調整できます。
